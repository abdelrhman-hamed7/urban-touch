## Project Title

**Urban Touch - Home Decor E-Commerce Website**

## Project Description

Urban Touch is a modern no-code e-commerce website designed for selling stylish home decor products online. The website was created using Wix, a no-code website builder, to demonstrate how an online store can be developed without writing code.

The store focuses on elegant and affordable home decoration products that help customers improve the appearance and comfort of their living spaces. Urban Touch provides a simple shopping experience where users can view products, read descriptions, check prices, and add items to the cart.

## Objective of the Project

The main objective of this project is to design and develop a simple e-commerce website using a no-code platform. The project demonstrates basic e-commerce features such as product display, navigation, contact information, and cart interaction.

## Platform Used

The website was developed using **Wix**.

Wix was chosen because it is beginner-friendly and provides ready-made tools for designing websites, adding products, creating pages, and enabling cart functionality without programming.

## Website Pages

The Urban Touch website includes the following pages:

### 1. Home Page

The Home page introduces the store with the name **Urban Touch** and a welcoming message. It also includes a modern interior design image and a **Shop Now** button that directs users to the shop section.

### 2. Shop / Products Page

The Shop page displays the available home decor products. Each product includes an image, product name, price, short description, and an Add to Cart button.

### 3. About Page

The About page explains the purpose of Urban Touch and describes the store mission. It presents the business as a home decor store that helps customers create beautiful and comfortable living spaces.

### 4. Contact Page

The Contact page provides store contact information and allows customers to reach the business for questions, support, or orders.

### 5. Cart Page

The Cart page allows customers to view products they have added to the cart. This provides a basic e-commerce interaction for the website.


## Features Implemented
